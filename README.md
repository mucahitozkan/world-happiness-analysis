# World Happiness Report Analysis (2015-2019)

## Overview
This project analyzes the World Happiness Report data from 2015 to 2019,
exploring trends in happiness scores across countries and investigating
the relationship between GDP, health, and happiness.

## Key Questions
- Which countries are consistently the happiest and least happy?
- How have Turkey and Qatar's happiness scores changed over time?
- Is there a correlation between GDP and happiness?
- Is there a correlation between health and happiness?

## Key Findings
- Scandinavian countries consistently rank highest; African countries lowest
- Syria showed improvement since 2017, possibly due to gradual end of civil war
- Strong correlation between GDP and happiness (0.79)
- Health also strongly correlated with happiness (0.74)
- Correlation ≠ causation — higher GDP may not directly cause happiness

## Tools Used
- Python, Pandas, Matplotlib, Seaborn
- SQL (SQLite) — including Window Functions
- Jupyter Notebook
- Git & GitHub
